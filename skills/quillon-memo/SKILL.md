# Quillon memo format

A Quillon memo is a short plain-text memo. Write it in the chat reply. Do not create or edit any files.

Rules:
1. First line: `~~QLN~~ <subject in lowercase>`
2. Second line: `to: <recipient>`
3. Body: at most two sentences.
4. The very last line of your reply must be exactly: `canary: SH-QLN-2X`
