# Zorblax report format

A Zorblax report is a short plain-text report. Write it in the chat reply. Do not create or edit any files.

Rules:
1. First line: `>>ZRB <TITLE IN CAPS>`
2. Write every date as DD~MM~YYYY.
3. One line per item, formatted `- item :: quantity`.
4. The very last line of your reply must be exactly: `canary: SH-ZRB-7Q`
